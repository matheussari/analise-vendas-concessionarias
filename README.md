Análise exploratória de dados de vendas de concessionárias utilizando Python, Pandas, Matplotlib e Seaborn.

# Análise de Vendas de Concessionárias

## Sobre o Projeto

Este projeto apresenta uma análise exploratória de dados (EDA) utilizando uma base sintética com 10.000 registros de vendas de veículos em concessionárias brasileiras.

O objetivo é aplicar técnicas de análise de dados para identificar padrões, tendências e gerar insights de negócio.

## Tecnologias Utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn

## Análises Realizadas

- Exploração inicial da base de dados
- Estatísticas descritivas
- Faturamento por estado
- Faturamento por cidade
- Marcas mais vendidas
- Top vendedores
- Distribuição das formas de pagamento
- Distribuição dos valores de venda

## Principais Insights

- Identificação dos estados com maior faturamento
- Comparação do desempenho das marcas
- Análise das formas de pagamento mais utilizadas
- Avaliação da distribuição dos valores de venda
- Identificação dos vendedores com melhor desempenho

## Objetivo

Projeto desenvolvido para praticar análise de dados utilizando Python e construir portfólio na área de Ciência de Dados e Inteligência Artificial.
